# 依赖与本地资源

## 联网首次安装

0.3.0 的 online.zip 附适配控制 APK、Copyparty SFX 与 OpenSpeedTest 网页资源，不含个人设备镜像或完整 Linux 二进制环境。缺失网页资源从上游或本次 Release 下载并校验；固定版本和哈希见 `resources.json`。

设备以 Alpine 3.22.6 aarch64 为基础，执行 `build-rootfs.sh` 安装 Samba、Nginx、Avahi、iperf3、Paramiko、密钥生成器和 dnsmasq 等依赖。apk 保留签名验证，依赖使用 3.22 仓库当时提供的版本；清单记录在 `/usr/share/rk3399-nas/`。基础镜像与网页版本固定，依赖并非长期冻结快照。

维护者可从干净环境构建本地 `payload/alpine-nas-clean.tar.gz`，配套 `payload/rootfs.sha256`；首次安装优先使用它。必须卸载 proc/sys/dev 后归档，不得从运行 NAS 导出。本次公开 Release 不分发该离线镜像。

## Windows ADB

从 [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) 下载 Windows 版本，将 adb.exe、AdbWinApi.dll、AdbWinUsbApi.dll 放入 tools/。也可将 adb 加入 PATH，或用 `-AdbPath` 指定路径。

## 已有 Alpine NAS

设备须已有 `/data/local/alpine-nas`、正常的 proc/dev/sys 挂载、Samba admin 账号，以及 Copyparty 文件服务账号。

| 依赖 | 用途 |
| --- | --- |
| Samba：smbd、smbcontrol、testparm | 文件共享与配置验证 |
| Python 3、py3-paramiko | 共享配置、SFTP 及身份迁移 |
| Copyparty 1.20.21 开发基线 | HTTP、WebDAV、FTP、SFTP |
| Nginx（含 sub_filter 模块） | 统一网页入口和代理 |
| Avahi | a.local / mDNS |
| iperf3 | 5201 测速服务 |
| awk、chroot、netstat、Android sm | 挂载检查、健康检查和卷管理 |

默认升级不自动联网安装依赖；缺少软件包时可先在自维护 chroot 中准备。`-Fresh` 联网流程使用完整构建脚本。

Copyparty 自解包程序须位于 `/opt/copyparty-sfx.py`；Avahi 配置须位于 `/etc/avahi/avahi-daemon.conf`。首次从 Primitive FTPd 迁移，还须保留其原偏好文件和 Ed25519 密钥。已迁移设备须保留 `/etc/nas-ssh/ssh_host_ed25519_key`。

本次提供联网首次安装包，不发布个人 rootfs、密码数据库、运行会话或私钥。

## 测速与控制 App

- 原 OpenSpeedTest Android 服务需能监听 3000；升级保留其原启动机制，不重新安装 APK。
- 存储管理页面需要支持 /api/v1/storage 的 RK3399 Control App，认证服务监听 8765。
- 可选本地 APK 文件名为 `payload/rk3399-control.apk`，安装时加 `-InstallControl`。它不进入 Git。
- 旧 Primitive FTPd APK 不再是新版运行依赖，旧脚本仅保存在 legacy/v0.1.0/。

## 校验

SHA256SUMS.txt 包含部署入口、资源准备脚本、资源锁和 device/ 文件。修改源码后需要重建清单，文本使用 LF 行尾。

资源锁验证自动下载内容和 Release 配套控制 APK；本地离线镜像另有哈希清单。第三方许可见 [依赖声明](../THIRD_PARTY_NOTICES.md)。
