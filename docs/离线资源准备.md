# 离线资源准备

GitHub 仓库只发布脚本和配置。以下资源须自行从可信来源准备，不随本次源码发布分发，也没有完整离线包 Release。

## Windows ADB

从 [Android Platform Tools 官方页面](https://developer.android.com/tools/releases/platform-tools) 下载 Windows 版本，将同一套文件放入 tools/：

```text
tools/adb.exe
tools/AdbWinApi.dll
tools/AdbWinUsbApi.dll
```

请阅读下载来源的许可条款；第三方文件不适用本项目 MIT 许可。

## APK

旧部署脚本要求以下文件名：

```text
payload/primitiveFTPd-7.5.apk
payload/openspeedtest-base.apk
payload/openspeedtest-en.apk
payload/openspeedtest-xhdpi.apk
payload/openspeedtest-zh.apk
```

- Primitive FTPd 的来源为 [上游项目](https://github.com/wolpi/prim-ftpd)。7.5 是旧版接口基线，存在 [已知安全问题](https://github.com/wolpi/prim-ftpd/security/advisories/GHSA-j72x-x52h-247j)。此仓库不推荐为日常使用特意安装有漏洞的旧版；升级后的设置界面与脚本需要另行适配验证。
- OpenSpeedTest 从 [官方页面](https://openspeedtest.com/) 获取 Android 安装资源。上述 base 与 split APK 必须来自同一版本、同一签名，不能将单一 APK 改名后充当分包。
- 上游 HTML5 Speed-Test 项目的许可不自动证明 Android APK 的再分发许可。本次不分发这些 APK。

## Alpine rootfs

`payload/alpine-nas-ready.tar` **不是普通 Alpine minirootfs**。它是旧脚本依赖的已配置 ARM64 环境，至少需要：

| 路径 / 内容 | 用途 |
| --- | --- |
| /usr/sbin/smbd、Samba 依赖与账号数据库 | SMB 共享及 admin 账号 |
| /usr/bin/python3 | 运行 Copyparty |
| /opt/copyparty-sfx.py | HTTP 文件服务 |
| /usr/sbin/dnsmasq | 电脑直连 LAN DHCP |
| /etc/passwd 中的 admin 与 Samba 认证 | 与示例账号匹配 |
| /etc/samba、/var/log、挂载目录 | 配置及服务运行位置 |

原私有归档还包含设备生成的证书私钥、会话数据库、Samba 身份数据库和历史日志，所以不提供该原文件。**没有完成干净 rootfs 的构建、账号初始化与实机验证前，本仓库不能独立完成部署。**

如自行构建，应从 [Alpine 官方 ARM64 minirootfs](https://alpinelinux.org/downloads/) 开始安装依赖，在自己的环境初始化账号并遵守各依赖许可。不要将旧设备的运行目录直接作为公开镜像。此说明不是已验证的完整构建配方。

## 校验与公开范围

SHA256SUMS.txt 只涵盖源码中的部署脚本与配置，不为自行下载的二进制提供可信哈希，原 deploy.ps1 也不会自动验证它。第三方资源应使用对应发行方提供的校验信息。

payload/ 的归档和 APK、tools/ 的 EXE / DLL 已由 .gitignore 排除。任何未来的离线包发布都应单独检查密钥、会话、日志、账号初始化、许可证和全新设备部署。
